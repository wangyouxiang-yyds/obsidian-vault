## 最終決議(設計全文的正本=repo `TODO/15_Prithvi_pilot.md`「接入方案」節,本檔只記骨架)
1. 路線:vendor 官方 HF prithvi_mae.py encoder + pin 版 terratorch UPerNet/scale modules,不裝 terratorch;vendored 檔記 upstream repo/commit/license/SHA256。
2. 300M 非 TL(taps [5,11,17,23]);600M 不進首輪。
3. 波段 8→6:index [1,2,3,5,6,7]=B02/B03/B04/B8A/B11/B12,丟 B01/B08;不做通道擴充/learned adapter。
4. 值域:/10000 後官方統計填 yaml mean/std 槽(mean [0,.1087,.1342,.1433,0,.2734,.1958,.1363]、std [1,.2248,.2179,.2178,1,.1850,.1242,.1049])。
5. 256×256、pos-embed bicubic 插值、T=1 顯式 [B,6,1,256,256]。
6. head=UPerNet(decoder 256);linear_smoke 僅測試用,yaml 選到即拒啟動。
7. 全微調、backbone_lr_mult 0.1;AMP+activation checkpointing;物理 batch preflight 定(預估 2),accumulation 補足 effective 16。
8. 程式:main/prithvi_backbone.py、prithvi_upernet.py、fetch_prithvi_checkpoint.py、test_prithvi_shapes.py(哨兵值驗波段順序+norm 等價 atol≤1e-6+C6)+ deeplab_adapter.py 加 model_family 'prithvi_eo_v2';C6 禁泛用 strict=False,MAE keys 明確 prefix allowlist。
9. pilot 預註冊:fold1;comparator=啟動前已完成同 fold V3 家族最佳(機械化排名=fold1 pooled_oil_iou,tie-break 較早/較簡,鎖後不換;今日=tversky fold1 0.4376);GO=Δpooled_oil_iou≥+0.030 且 per-scene one-sided Wilcoxon p<0.05 且無 protocol 異常;次要機制指標預註冊;Phase 0 對齊閘門全過才准訓練;六條反證條件寫死(含 OOM fallback 失敗即停不得換 head/縮 patch/改 600M)。
10. 結論邊界:GO≠勝 recon 0.3915;NO-GO 不外推多時相/600M/8band adapter。
