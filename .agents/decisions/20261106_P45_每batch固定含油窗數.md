# P45 實驗卡：P44 ROI 重疊滑窗 ＋「每個 batch 固定 k 個含油窗」（k＝1／2／4），全球排除臺灣 → 臺灣 24 景

- 狀態：**FROZEN v1（2026-11-06）**。凍結物：本卡 `FROZEN_CARD.sha256`、程式 `FROZEN_CODE.sha256`；清單沿用 P44 `FROZEN_LISTS.sha256`。
- **未經 Codex 協商**：使用者 2026-11-06 告知 Codex 用量已用盡，指示「你自己想一想就跑吧」。本卡與程式只有 Claude 自審，
  以 50 項單元測試＋GPU smoke＋負向閘門測試代替外部審查。這是與 P44 流程的差異，報告時要揭露。
- 授權：使用者同句授權 launch（`launch.sh`）。讀臺灣 GT（`evaluate_p45.py evaluate`）另需使用者授權。
- 取代：無。P44 凍結卡與結果不變。
- 設計來源：使用者 11-06 裁決「每一個 batch 都讓他有學到油」；k 格點與其餘細節由 Claude 訂定（見 §3）。

## 1. Problem（來自 P44 結果）
P44（自然比例：每 batch 平均 0.43 個含油窗、約 65% batch 全背景）臺灣 24 張 ROI pooled OilIoU 0.300，高於 P12 三 seed（0.209–0.223），
增益來自 FP 減半（2.07M→0.99M 像素、孤立誤判塊 1,167→257）。但 recall 分布變差：10 景 recall 降 >0.1，
GT 油塊偵測率各大小級距都低於 P12（例如 1k–10k px：79% vs 94%），且 3 景（2026-09／10 S2：50RQN、51RTK、50RPN）幾乎全漏，
漏判像素的油機率多 <0.1（篤定判背景，調閾值救不回）。VAL 同樣偏漏判（best pred/gt 0.68，全程 0.004–0.176 震盪）。
機制推測：batch 加總 Tversky 下，全背景 batch 梯度≈0（6.6e-5 vs 1.3），有油的 batch 又多是 1 個含油窗配 15 個背景窗，FP 項壓力大 → 偏保守。

## 2. Research Question
**只改「每個 optimizer batch 的組成」（固定 k 個含油窗＋16−k 個背景窗），其餘全照 P44 凍結設定時，
VAL 選出的 k，其臺灣 24 張 ROI pooled OilIoU 是否高於 P44？相對 P12 三 seed 的升級／停止判定為何？**
這是單一變數（batch 組成）的比較，但只有單 seed，且 P44 的選模點敏感（best 0.300 vs last 0.163），結果屬篩選，不是確認。

## 3. Method（除下列各點外，全部＝P44 FROZEN v1 §5）
- **資料、ROI、窗、無效像素、VAL／臺灣算子**：完全沿用 P44（同一份清單 `/home/alanyh/oil_dataset/new/_p44_roi_sliding_20261106/lists/`，
  同一 `rois_taiwan.csv`、同一 `p44_common.predict_scene`／`confusion`／`pooled`）。程式直接 import P44 凍結目錄的模組，不複製、不修改。
- **池**：含油窗＝TRAIN 保留窗中 `oil_px>0`（7,123）；背景窗＝保留窗中 `oil_px==0`（258,373）。`oil_px` 是原始 mask 值 0 的像素數
  （無效像素覆寫前；保留窗無效像素 ≤10%）。
- **取樣器 `FixedKBatchSampler`**：每個 batch＝k 個含油窗＋(16−k) 個背景窗。兩個池各自是一條 permutation 串流
  （第 p 輪 `randperm(n, seed=42×1,000,003＋2p＋s)`，s＝0 油／1 背景），虛擬 epoch e 取兩條串流的連續段；無狀態、可重現。
  k＝1／2／4 時含油窗每虛擬 epoch 用 4,000／8,000／16,000 次（油池約 0.56／1.1／2.2 輪）。
- **k 格點＝{1, 2, 4}**（Claude 訂定，無文獻或數據推導）：兩個已知端點為 P44≈0.43（FP 少、漏判多）與 P12≈7
  （GT 置中 patch 約佔每 epoch 樣本 45%；FP 多、pred/gt≈2），格點取兩端之間倍數遞增。像素層級油背比定義（使用者曾偏好像素口徑）未採用，
  已在對話中說明，使用者選擇以每 batch 含油窗數執行。
- **訓練**：模型、loss（Tversky α0.3/β0.7 batch 加總）、增強、AdamW、lr、AMP、clip、batch 16、seed 42、4,000 步／虛擬 epoch、
  上限 40、patience 8、cosine T_max 160k、選 best＝VAL pooled 油 IoU：全部同 P44。三個 k 依序各跑一次（k1→k2→k4）。
- **只影響顯示／紀錄、不影響數值的改動**：tqdm 進度條＋舊 main_runner 格式的每 epoch 摘要（使用者要求）；
  `history.csv` 多記 T-Oil IoU／T-mIoU（訓練 batch argmax，no_grad）、V-Loss（VAL 全部 ROI 的 soft Tversky 加總後算一次，
  公式同訓練 loss，測試驗證與 `TverskyLoss` 相等）、V-mIoU（油與背景 IoU 平均）。
- **k 的選擇**：三個 run 各自 best checkpoint 的 VAL pooled 油 IoU 取最高；同分取較小 k。**不得用臺灣結果選 k**。
- **臺灣預測**：三個 k 的 best 都以 P44 測試算子推論（步距 128＋TTA、fp32）。對照預測（P44_best、P12_S42／43／44）直接沿用 P44 已封存的預測；
  seal 時先以 P44 自己的 `collect()` 重算並比對 P44 `eval_seal.json`（SHA `435024cf…` 釘在 config），不符即中止。
- **VAL 診斷**：只對選中的 k 以測試算子跑一次（不得據此改選）。

## 4. Hypothesis
k 越大 → 每步都有油的梯度、FP 項相對壓力下降 → recall 上升、pred/gt 上升，FP 也可能回升；
預期存在某個 k 使臺灣 ROI pooled OilIoU 高於 P44（漏判救回多於誤判增加）。風險：k=4 過度預測（smoke 600 步時 VAL pred/gt≈5.6，屬早期狀態）。

## 5. Evaluation
- 主指標同 P44：臺灣 24 張 ROI pooled OilIoU（27 ROI 聯集∩有效像素，TP/FP/FN 加總算一次）；19／新增 5 張分列；precision、recall、pred/gt。
- X＝VAL 選中 k 的臺灣值；Y＝P44_best（0.300，P44 封存預測、同程式重算）；R＝P12 三 seed。
- **硬失敗（先判）**：同 P44（臺灣 pooled 單一類別；臺灣 pred/gt<0.2；選中 run 的 VAL best pred/gt<0.2）。
- **相對 P44（主要問題）**：X−Y ≥ 0.03 → better_than_P44；Y−X ≥ 0.03 → worse_than_P44；其餘 within_margin_of_P44。
  P44 只有單一 run、且選模點敏感，0.03 只是篩選門檻，不代表穩定差異。
- **相對 P12**：同 P44 規則（X>max(R) 且 X−mean(R)≥0.03 → upgrade；X<min(R) → stop；其餘 indeterminate）。
- 描述性（不參與判定、不回頭選 k）：未選中 k 的臺灣值；逐景表；P44 分析同法的 GT 油塊偵測率（依大小級距）、孤立誤判塊數；
  P44 全漏的 3 景之 recall。
