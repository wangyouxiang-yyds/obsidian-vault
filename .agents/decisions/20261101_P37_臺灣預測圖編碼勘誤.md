## 發現

作者 SegFormer 推論輸出是 softmax；本案約定 `class 0=oil`、`class 1=background`，GoM 驗證使用 `argmax` 正確計分。`infer_target.py` 取 `model(...)[0,0]`（油機率），卻把 `probability >= 0.5` 直接儲存為 PNG 像素 **1**。`evaluate_target.py` 與合成測試則把 PNG 像素 **0** 當油。若直接將原封存 PNG 送進評估器，**正負類會反轉**。

合成回歸測試 `test_encoding_erratum.py` 以明確油區驗證：原編碼 IoU=0，更正為 0=oil／1=background 後 IoU=1。兩份原始封存圖共有 270×2 張；依原 PNG 逐檔反轉即可，不必重跑模型或碰 target GT。`*_oil_prob.npy` 是 float16，與原 float32 閾值圖有少量量化臨界差：final 191 像素、best 203 像素與 `float16 >=0.5` 不同，因此**不能**從 float16 機率檔重新閾值化；須反轉原 PNG 以保留原判斷。
