- P17 原版（舊 artifact，parity 參照）`0.4558`（0.519、0.393），best epoch 208。

**判定（依 §2 預註冊規則）**：

- 主比較 Δ = tva02 − tv03：macro **+0.0869**、05-22 **+0.1216**、天使輪 **+0.0523** → 兩事件皆同向超過 +0.005、且 macro ≥ +0.04 → 判定 **PROMISING**。預定動作：`tv03`、`tva02` 兩組都補 seed 43/44。
- 描述性（不進判定）：recall 上升（date-macro macro +0.1342，05-22 +0.1846、天使輪 +0.0837），precision 沒有下降（macro +0.0236；05-22 +0.0022、天使輪 +0.0450）。

**警訊（必須一併記載，不得單獨引用上面的 PROMISING 判定）**：

- `tv03 − P17 原版` = macro **−0.0908**（05-22 −0.1208、天使輪 −0.0608）。這是**同一 config、同一 seed**（`tv03` 與 P17 原版皆為 α0.3/β0.7、seed42）的跨版本重跑差，只差程式碼版本（main_runner/training_module/deeplab_adapter sha）與 GPU 訓練非決定性，差值卻與本次「效果」（macro +0.0869）同量級。
- `tva02 − P17 原版` = macro **−0.0039**（05-22 +0.0007、天使輪 −0.0086），接近零。
- 最可能的解讀：`tv03` 的 best checkpoint 選在很早的 epoch（73，對比 `tva02` 298、P17 原版 208），訓練不足導致表現差，**這很可能不是 0.2/0.8 本身的效果**，而是 `tv03` 這次重播運氣差（選到偏早、偏弱的 checkpoint）。換句話說，單 run 雜訊實際上比 P15 三 seed 單 run SD 外推估計的還大（§2 判定規則的 ε=0.005、+0.04 門檻原本就承認「零效果下仍有可觀機率誤判為 PROMISING」）。
- 因此**不得把這次結果直接寫成「0.2/0.8 比 0.3/0.7 有效」**；PROMISING 判定成立僅代表「依預註冊規則，值得補 seed 以分辨效果與雜訊」，不是效果本身已確認。
