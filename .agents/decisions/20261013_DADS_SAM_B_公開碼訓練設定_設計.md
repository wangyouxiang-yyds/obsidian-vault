# DADS-SAM B × 公開碼訓練設定 — 只改輸入與輸出的一次 run（seed 42）

日期：2026-10-13 Asia/Taipei。使用者指示（原話）：「我這邊想要請你幫我再跑一個實驗是 DADSSAM的 loss也幫我改成跟他一樣的，也就是使用Loss 為 0.7 DiceCE + 0.3 Focal，batch size = 2，固定訓練 100 epochs，取最後一個 epoch 的權重 所以簡單講就是改輸入與輸出而已」。
協商狀態：未經 Claude × Codex 協商。本檔在這個 run 的任何結果出現前寫成；事後不改。

## 目的與問題

目前報告裡的 DADS-SAM（B）用的是與基線相同的訓練設定（Tversky、AdamW、batch 16、早停、取驗證最佳），只有模型架構來自公開碼。這個 run 把訓練設定也換回公開碼的，回答：「除了輸入與輸出之外都照公開碼」時，GoM 訓練、臺灣測試的結果是多少。

## 做什麼

以正式 B（`MS6_DADS_SAM_B_public6_GoM_R1`，seed 42）的設定為底，只改訓練設定；`build_B_public_recipe.py` 逐鍵比對其餘相同。

| 項目 | 正式 B（現有三個 seed） | 本 run（公開碼 `train_port.py`／`config.yaml`） |
|---|---|---|
| Loss | Tversky（α 0.3、β 0.7） | 0.7 × DiceCE ＋ 0.3 × Focal（γ 2） |
| Optimizer | AdamW，weight decay 1e-3 | Adam，weight decay 1e-4 |
| 學習率 | 5e-5，cosine 遞減 | 1e-4，全程固定 |
| Batch size | 16 | 2 |
| Epoch | 最多 300，50 個 epoch 沒進步即停 | 固定 100，不早停 |
| 測試用權重 | 驗證 mIoU 最高的 epoch | 最後一個 epoch |
| 資料增強 | 與基線相同 | 無 |
| Gradient clipping | 1.0 | 無 |
| 精度 | fp16 混合精度 | fp32 |

使用者點名的是 loss、batch size、epoch 數、取最後權重；optimizer、學習率、增強、clipping、精度是我依「只改輸入與輸出」的說法一併照公開碼設定的（我的解讀）。

**沒有照公開碼的地方（輸入與輸出之外仍有一項）**
- Prompt：公開碼的 box 由標註的外接框算出（訓練、驗證、測試皆然），測試時等於把答案位置給模型。本 run 沿用 B 的固定整張圖 box `[0,0,1023,1023]`。
- 其餘與現有 B 相同：六波段輸入與正規化、256→1024 直接放大、patch embedding 3→6 通道（可訓練）、2 類、輸出 256×256；公開碼的 DSCA 不在計算圖內。

實作：`main/deeplab_adapter.py` 新增 `dataset.loss.type: dice_ce_focal` 與 `train_recipe: dads_sam_public` 兩個選項，未設時行為不變。容器沒有 monai，DiceCE 依其定義重寫；與 monai 1.3.2 `DiceCELoss` ＋ 公開碼 `FocalLoss` 在隨機輸入上比對，float64 的 loss 差 < 1e-15、梯度相對差 < 2e-16。

設定檔 `main/experiments_DADS_SAM_gomonly_B_public_recipe.yaml`；launcher `launch_B_public_recipe.sh`；結果 `/home/alanyh/oil_dataset/new/_dads_sam_runs/DADS_SAM_gomonly_B_public_recipe`。訓練結束後以最後一個 epoch 的權重做唯一一次臺灣測試。

## 開跑前的檢查

`smoke_B_public_recipe.py`（GoM 訓練 300 步＋完整 GoM 驗證，不讀臺灣資料）：PASS。loss 與學習率皆為有限值、學習率固定 1e-4；顯存峰值 15.9 GiB；訓練 3.6 步／秒、驗證 48 秒。300 步（600 張）時驗證 Oil IoU 為 0.000（全部判成背景），這麼早不足以判斷學不學得起來。

- 主數字：臺灣 9 景像素加總算一次的 Oil IoU／Precision／Recall／F1／BG IoU／mIoU，附混淆矩陣；同列 9 景各算再平均。

- 同時列 GoM 驗證的最後一個 epoch 與最佳 epoch 的 mIoU／Oil IoU。最佳 epoch 的權重不拿去測臺灣。

- 10-10 凍結卡對 B 的判定不因本 run 更改。

## 限制

- 單一 seed；B 的臺灣結果已看過，不是盲測。
- 與現有 B 相比同時改了九項（上表），結果的差異無法歸給其中任何一項。
- Prompt 與公開碼不同（見上）；資料是 GoM 衛星影像而非公開碼的無人機 RGB。
- 每個 epoch 仍會算 GoM 驗證指標並寫入 results.csv，但不用來選權重或停止。
- 臺灣只有 9 景、兩個事件。
