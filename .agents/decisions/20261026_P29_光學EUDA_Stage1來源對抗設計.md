## 1. Objective

檢驗在相同 GoM 來源監督訓練程序上加入臺灣影像的 Stage 1 不確定度對抗，能否改善固定歷史評估口徑的 target 油汙分割表現，並取得後續 Stage 2 可用的模型與逐像素預測。此實驗只比較 Stage 1；不制定 Stage 2 光學物理分組或 strong／weak 門檻。

## 2. Problem

現有 P14 GoM-only 是 source-only，未在訓練時使用臺灣影像。公開 EUDA-PLR 程式為三通道 SAR 流程，Stage I uncertainty 有 batch/device 錯誤，評估與選權重也有 target-GT 洩漏風險，不能原樣用於本案六波段光學影像。本案臺灣 19 張曾被用於探索且同時進入無標註 target 訓練與最後評估，因此是**非盲測的 transductive UDA**；即使數值改善，也不能推論未見臺灣影像的泛化。

## 3. Research Question

在同一原始 Prithvi EO V2 300M 初始化、同一 GoM source 清單／監督 loss／增強／optimizer／source update 預算、同 seed 與同 GoM validation 選模規則下，加入 19 張臺灣影像的 Stage 1 不確定度對抗後，固定臺灣 19 張的歷史 `gt_aware` pooled Oil IoU 是否比 source-only 上升，且不伴隨明顯已標油漏判、明確背景誤判或預測油面積崩潰？

**已否定路線檢查（R6-1）**：已查共用研究現況檔「已否定路線」及 2026-10-17 UDA 翻案決策。P27 Wakashio 單一比值優先候選已否定；P28 B08-dip 與品質排序不可判定。本案不用這些 Stage 2 proxy；2026-10-08「UDA 延後」已由使用者 2026-10-17 明確翻案。本案新增訊號是無標註臺灣 target 影像參與 Stage 1 對抗訓練。

## 4. Hypothesis

與同一訓練器的 source-only 相比，target 不確定度對抗可能改善固定 target 影像上的分割。但跨感測器、雲、填充值與 GT=255 未標區當背景的歷史評估偏差均可能使指標改善不代表真實精度提高。此假說是在看過同批臺灣資料的歷史結果後設定，只能作探索性判讀。

## 5. Method

### 對照與訓練

| 項目 | A：source-only | B：Stage 1 target adversarial |
| --- | --- | --- |
| Run | `MS6_EUDA_S1_source_only_S42/S43/S44` | `MS6_EUDA_S1_uncertainty_adv_S42/S43/S44` |
| 初始化／模型 | 同一原始 Prithvi EO V2 300M checkpoint；Prithvi＋DeepLabV3，6 個活躍波段 B02/B03/B04/B8A/B11/B12，256×256，油=0／背景=1 | 完全相同；不以 P14 `best.pt` 初始化 |
| Source | GoM R1 train 156 景：1,188 有油＋1,550 背景 patch；GoM source-val 39 景 | 相同 source minibatch 順序與增強 |
| Source loss | P14 Tversky α=0.3、β=0.7；raw GT 255→背景，沿用既定 source 語義 | 同左 |
| Target | 無 | 臺灣 19 個 VRT，僅影像，不讀任何臺灣 GT／mask／GT-aware patch；從 27,587 個候選完整 256 網格窗依索引輪流選景（每景均衡），景內以固定 seed 隨機選窗口；完整六波段像素中全零、非有限值或任一絕對值 >1e6 的比例須 ≤10%，失敗則同景重抽，最多 32 次後停止 |
| 額外目標 | λ_adv=0，不使用 target | source／target 二類預測的不確定度圖 `1−|p_oil−p_bg|`；判別器 Adam 1e−4，分割器對抗權重 λ_adv=0.001 |
| Optimizer／預算 | 分割器 AdamW，head 5e−5、backbone 5e−6；100 epoch、每 epoch 171 source updates，共 17,100；cosine `T_max=300`；不早停 | 完全同左，額外 target／判別器更新不計入 source 更新預算 |
| Checkpoint | 僅 GoM source-val mIoU 選 best | 同左；不依臺灣標註選 epoch、權重或閾值 |

三個配對 seed 為 42、43、44。A/B 走同一新訓練器，唯一實驗處理是 B 啟用 image-only target 與 uncertainty-adversarial 分支；B 的額外計算是該處理的一部分。固定的 target 清單 SHA-256 為 `dd33636f15e401144565b5c98648b5636d09baf608e3914ffe5aea509118173f`，候選窗口清單 SHA-256 為 `5a24109da05b44fc31e25abbab2c77ef2934209cb848cd4b5b8fce9f68475dc0`。候選窗口由影像內固定 16×16 採樣點初篩，不表示全 27,587 窗均已全解析度驗證；訓練時逐窗再做完整像素守門。此守門不辨識雲或陸地。只取 42×42 個完整網格窗／scene，排除右／下 28 px 補邊。

**對照組與 estimand（R6-2）**：主對照是同 seed 的 A。主指標 `_kind=recon(gt_aware)`：每個 seed 在固定臺灣 19 張、同一 GT-aware 256 patch 覆蓋聯集上，將 raw GT 255 視為背景，將像素 TP／FP／FN 加總後計 pooled Oil IoU；每 seed 算 B−A，最後取三個配對差值平均。原 9 張、新 10 張、10 個日期群分列描述，不把同日期多 tile 當獨立樣本。GoM validation 僅供選權重，其 train／val 非事件獨立，workbook 即時 `test_txt` 指向 GoM val，不能稱獨立 GoM test。

同時報全景原始 GT=0 已標油像素 recall、全景預測油面積、以及天使輪 7 張原始 GT=1 明確背景像素 FPR。前兩者不能辨識 GT255 區域是否為真 FP；最後一項只代表具有明確背景標記的子集。主 `gt_aware` Oil IoU 因 GT255→背景而**不是全景真實 IoU 或 precision**。同一 19 張影像同時做 image-only 訓練與評估，也不是 unseen-target test。

## 6. Expected Evidence

此處是**探索性續做 Stage 2 的操作門檻**，不是確認真實分割精度提升的顯著性檢定。正負 0.03 約是本專案以往一個 run 間 SD 的實務幅度，且是在看過臺灣歷史結果後提出，不能稱獨立先驗門檻。

- **支持繼續到下一張 Stage 2 設計卡**：三個配對 seed 的 target 歷史口徑 pooled Oil IoU 差值均 `>0`，三差值平均 `≥+0.03`；三 seed 平均的全景已標油 recall 差值 `≥−0.02`；天使輪明確背景 FPR 差值平均 `≤+0.02`；每個 seed 的全景預測油面積 `B/A` 均在 `[0.5,2.0]`。全部條件同時成立才算支持探索性續做。
- **否定本次固定 Stage 1 設定的優先性**：三個配對差值均 `≤0`，且平均差值 `≤−0.03`。不延伸為否定所有光學 UDA。
- **不可判定**：介於以上兩者之間，或任一必要指標無法依同一口徑取得。不得事後用視覺挑圖或 source-val 最佳值改判。三個 seed、10 個相關日期群與 GT255 未標區均限制解釋；要確認真實分割提升，另需充分標註、獨立的 target 測試集。
