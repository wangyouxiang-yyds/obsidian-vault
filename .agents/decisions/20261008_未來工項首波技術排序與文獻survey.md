- G0-c 對照組 C × seed 42/43/44 → three-seed empirical envelope(不稱 95% band);source-val 進平台後每 2–5 epoch 存權重(不存 optimizer state)。

- G0-e 負資料:d1=MADOS 已標註非油像素(scene/tile 永久 holdout;只算 annotated-negative pixel FPR 與油–look-alike 混淆;標示 preprocessing-shift 外部 stress test,僅 S2);d2=完整審閱、有有效水域面積分母的無油 scenes/regions 才支撐 scene FPR 與 FP area/km²;臺灣 342 景核實只用於最終臺灣驗證。**負資料到位前不得主張誤報率改善。**

### Track B 模型實驗(GPU)
- **B1 細油污機制實驗族 C/Z/R(共用對照,各 3 seeds;先 C、Z,再 R)**〔工項四優化、二(2)、一(3)〕
  - Z=zoom-out/field-of-view 增強(讀較大視窗降採樣回 256)。假說=「較小相對尺度+較大背景 context 是否有利於細線」,不得解釋為純粹補細樣本。
    - s ~ LogUniform(s_min, 1),s_min = max(3 ÷ w̃_source-train, 256 ÷ W_max, 0.25);w̃ 只由重切後 GoM source-train 計算;W_max=實際允許讀取的最大視窗;施作機率 0.5 固定不掃;所有感測器同分布、結果按 S2/L8/L9 分層。臺灣線寬只作動機揭露。
    - mask 重採樣法只依 source-train 幾何保真度(component 消失率、面積與線寬偏差)選定並凍結;細線消失後 patch 的處置同時凍結;geometry smoke gate 若消失過多先提高 s_min。
  - R=P23 入口 2× 重訓(Prithvi 預訓練權重微調)。
  - 判準:主指標=cluster-macro 細線 IoU;次指標=原 52-patch pooled IoU、線寬比、precision、recall。有效=3/3 seeds 配對同方向、多數可評估 cluster 同方向、配對平均超過 max(P23 卡實質門檻, C 的 three-seed envelope);護欄沿用 P23 卡。**P23 卡須依 G0-a 與 cluster-macro 修訂後才凍結。**臺灣只描述。
  - B1 後決策樹:Z 過 R 不過→B3;R 過或仍有穩定寬度膨脹→B2a;Z、R 皆過→先測 Z+R;皆不過→回 A1/A3(若確認局部解析失真可做 B2a,不直接投入大規模 B3)。
- B2 局部高解析旁路(分閘):B2a=1/4 淺層六波段 stem+skip;B2b=仍膨脹才加 PointRend 式邊界細化;B2c=A1/A3 證明低油–水反差為獨立失敗 strata 才加顯式反差特徵。〔工項四〕
- B3 有條件 mask copy-paste(含 object-only 縮放):前置 A1、G0-f、G0-g;背景須為確認水域;合理性閘=六波段局部油–水反差 MMD(事前固定 kernel/bandwidth)+反射率合法範圍+接縫梯度+分感測器+連通區消失率;兩組=海外油×海外背景(論文可用)/海外油×已核實無油臺灣背景(target-informed 計畫支線)。〔工項二(2)〕
- B4a 事後 checkpoint averaging 篩選(不稱 SWAD;window 事前固定;B1 primary 仍用同一 best.pt 政策)。
- B4b PEFT(條件式第二波;單一預註冊 LoRA 設定)。
- B5 look-alike 多類輔助訓練(G0-e 量到實質誤報後;只用 MADOS 非 holdout)。
- B6 source-only 校準與固定操作閾值(d2 到位後;CPU)。〔工項五〕
