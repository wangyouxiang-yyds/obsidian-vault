# 光學油污 Stage 1 自動 ROI：方法方向共識

**狀態**：僅選定第一個可行性試驗的研究方向；不是實驗卡、模型或標註規則凍結，不授權訓練、修改資料、讀取新的外測 GT 或宣稱泛化。使用者要求 Codex 與 Claude 討論「已有 Stage 2 後，Stage 1 如何自動找油污 bbox」。

**主持與對手**：Codex 主持；Claude Code CLI 2.1.322，要求模型 `claude-opus-5`、effort high，實際模型未由 JSON metadata 回報，未發現降級證據。同一對手 session `b5f46adc-6afe-4916-a05f-a1cd2948b13c`，三輪有效協商；先前一次首呼叫無輸出且 exit 1，之後以簡短 probe 建立 session，不能把失敗呼叫算成 Claude 意見。

## 問題背景與證據邊界

- 現有 P44 Stage 2 是六波段光學影像的 Prithvi-EO-2.0＋DeepLabV3 分割器；以 GT 衍生油區外框建 3,840×3,840 oracle ROI，再以原生 256×256、stride 128 視窗分割。此 ROI 規則不是未知影像上的自動定位器。依據：[[20261106_P44_ROI重疊滑窗全球排除臺灣設計]]；repo `analysis/p44_roi_sliding_global_20261106/P44_CARD_DRAFT.md`。
- TRAIN 最大連通油區外框長邊 3,430 px，只是已見樣本最大值；新影像可能更大，也可能有多個相距很遠的油區。既有 VAL 分割漏判偏多，Stage 1 必須先保住油區覆蓋，不能只追求框 precision。
- 來源／地點群是代理資訊，不是已確認事件 ID；現況檔記 56 個代理群，其中 GoM 41 個地點代理群。P44 VAL 曾用於 Stage 2 選模，不能當全管線未見事件的獨立測試。相關資料邊界見 [[來源分折與封存測試]] 及 institution `research/oil_spill_project_status.md`。

## 逐輪協商

| 回合 | 分歧、修改與回覆 |

**收斂原因**：兩方同意 YOLOv8 作第一個 Stage 1 可行性候選，且把標註、尺度、來源群及公平計分的主要疑慮納入前置診斷；Claude 最後一輪已準確複述候選方案及風險處理。第一輪的低解析度 screener 仍可作對照探索，並非已被實驗否定。

## 方向性決議

1. **先做資料與標註盤點**：只用 source TRAIN 的油污像素 GT，按事前固定的油區分組規則產生多個 bbox；檢查大油、碎片、邊界與可疑未標註區。未經抽查可信的「無油」視窗不得直接作負樣本。這一步尚未規定最終分組閾值或負窗規則。
2. **第一個 Stage 1 候選為監督式 YOLOv8**：以大、小兩種物理範圍的重疊影像 tile 保留大型油區完整視野與小油細節；大 tile 覆蓋至少 TRAIN 已見 3,430 px 長邊後縮放到偵測器輸入，小 tile 維持原生細節。只有截斷油區、且沒有可靠 ignore 處置的 tile 先排除訓練；取窗規則須使 TRAIN 油區至少有完整視野。具體 tile 尺寸、步距、標註裁切、模型通道接法與計算預算留待實驗卡凍結。
3. **串接保持 Stage 2 不動**：將不同尺度的預測框映回原始座標，去重／合併，再依固定規則轉成多個 3,840 ROI；預測框大於單一 ROI 時用多個 ROI 覆蓋。框合併與 ROI 鋪設是 Stage 1 方法的一部分，不得在看外測結果後改規則。
4. **評估先看是否漏油，再看端到端**：報 GT 油像素落在候選 ROI 內的比例、油區召回（含尺寸與影像邊緣分層）、每景 ROI 數及 Stage 2 分割結果。比較 GT oracle ROI 與自動 ROI 時，兩者在**同一完整有效影像／預先固定 AOI** 上累計 TP／FP／FN，兩者 ROI 外均預設背景；不得各自在自己的 ROI 聯集算 IoU 後比較。
5. **證據分級**：P44 source VAL 可作工程診斷，須揭露 Stage 2 已用此 VAL 選模及來源／地點可能交疊；來源群隔離另行稽核。臺灣 24 景已反覆查看，只在規則鎖定後描述性報告，不用於選模型、閾值或 ROI 規則。強泛化主張需另有獨立資料。

## 未選為第一個候選的方向

- 低解析度六波段 screener：可作對照探索；需獨立訓練或先檢驗尺度，不能直接把原生解析度 Stage 2 當零訓練 screener。GT mask 降採後的存活只屬幾何診斷，不能宣稱為模型召回上界。
- HSBA 候選區、Faster R-CNN：保留備選；目前沒有比上述首個可行性試驗更直接的本專案證據。SAM-OIL 的 box-prompt SAM 消費 bbox，不解決 Stage 1 自動出框；現有 Stage 2 不因此改動。

## 殘餘風險、少數意見與後續驗證

- Claude 的非阻斷提醒：推論遇到截斷油區與超過 TRAIN 最大值的油區；兩尺度之間可能有尺寸接縫；只取可靠負窗可能低估耀光、雲、風影、船等相似物；ROI 數與算力預算尚未定。應把邊緣／超大油區與連續尺寸召回曲線納入 pilot 診斷。
- Codex 的保留：YOLOv8 可先試，不代表已證明優於低解析度提案；需讓實際 GT 油像素覆蓋率、ROI 成本和完整流程結果決定是否續行。沒有少數意見要求現在改用另一個正式主線。
- 下一步若使用者要正式實驗：先寫九步驟卡第 1–6 步，明訂候選框分組、截斷與負窗處理、兩尺度 tile 與 ROI 轉換、資料角色、成本與判定門檻，再依專案規則處理訓練授權。
