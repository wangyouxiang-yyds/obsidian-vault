# 背景一：GeoAgent（Liu et al., ICCV 2023, Seeing Beyond the Patch）
- 雙分支共用權重分割網路：local patch 原解析度；context 以 patch 為中心擴大 a 倍再降採樣回同尺寸；context 特徵依地理位置切出對應 local 的區域後與 local 特徵 concat→3×3 conv→1×1 conv→softmax。
- Scale Control Agent（A2C）看整景縮圖＋位置 mask 決定 a；reward=相對 local-only 的分數改善（需像素 GT）。
- 消融：context-only 隨倍率增加掉分；固定尺度有時傷害、最佳尺度隨資料集變；random scale 優於 local-only；GeoAgent 最好。三個 1–4 m GF-2 多類 LULC 資料集 mIoU +5～+13；無重複實驗、無算力公平。

# 背景二：本專案歷史（P11，GT-centric 時代）

# 背景三：現行 P44 架構（使用者 11-10 定為基線）
- 模型：Prithvi-EO-2.0-300M encoder（6 波段 B02/B03/B04/B8A/B11/B12，從 8 波段 VRT 取；16px patch → 16×16 tokens×1024，取第 23 層）＋ DeepLabV3 ASPP(6,12,18) head，2 類。輸入 256×256@10m。
- 取樣：以 GT 最大單一連通油區長邊 3,430 → ROI 3840×3840（多油區 first-fit 可多 ROI），ROI 內步距 128 滑窗，**背景不挑（自然比例）**。TRAIN 298 景／265,496 窗，VAL 37 景／8,724 窗（tile／具名事件整組抽）；全球資料排除臺灣（+菲律賓）。含油窗約 2.7%；每 batch 有油的比例約 0.34；油像素佔訓練像素約 0.19%。
- 訓練：batch 16、AdamW（enc lr 5e-6、head 5e-5、wd 1e-3）、AMP、clip 1.0、Cosine；virtual epoch=4000 steps，最多 40 VE，patience 8；Tversky α0.3/β0.7（batch 加總；已知全背景 batch 梯度≈0）。增強：RandomResizedCrop(256,(0.9,1),p.5)、H/V flip、RandRot90 p.8、GaussNoise、BrightnessContrast。約 10.6 it/s，每 VE 約 6.3 分＋VAL 2 分。
- 選模：VAL ROI 拼接（stride 256、無 TTA）pooled 油 IoU。測試推論：stride 128＋TTA(orig/hflip/vflip)，logit 平均拼接。
- 讀圖：rasterio VRT window（boundless fill 0）；無效像素→ignore 255。VRT DN 有 +1000 offset（對光譜指數重要，對正規化輸入無影響）。
- 結果（臺灣 ROI 口徑，pooled 油 IoU）：P44 三 seed S42/S43/S44 = 0.300／0.351／0.045（S44 塌縮全背景）。VAL best（S42）pooled IoU 0.188、P 0.44、R 0.25、pred/gt 0.56（嚴重漏判）。
- 其他 ROI 實驗：P45 每 batch 固定油窗 k=4 臺灣 0.238（worse）；P46/P48 H1′（1:1 隨機背景＋0.5 OOF HNM）三 seed 0.311±0.014 vs P44 0.232±0.164 = indistinguishable；P50 換 UperNet head not better。P51（GoM-only）目前在 GPU 上跑三 seed。
