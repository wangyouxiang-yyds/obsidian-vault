## 設計（對 P32 單因子）

唯一改變：Stage I **與** Stage III 的判別器輸入，由 U＝1−|p0−p1|（1 通道）改為 AdvEnt `prob_2_entropy`（2 通道）。

- 公式：E_c＝−p_c·log2(p_c+1e-30)/log2(2)；softmax 以 float32 計算；2 通道，不相加、不重新縮放。
- 判別器 D：第一層 conv `in_channels` 1→2，其餘完全相同；Stage I／Stage III 每次 run 都用全新 D，不載入 P32 的 D 狀態。
- λ_adv .001 與 D 的 learning rate 不重調；尺度差異列為限制，且不用臺灣 GT 校準。
- 其餘全同 P32：
  - 270 窗、`window_uniform`、17,100 步、GoM-val 選 best、S42／43／44。
  - Stage II 同公式、同 tie-break、180／90，以各 seed 自己的 P33 Stage I 重新排序。
  - Stage III：`fixed_stage1_argmax` cache 取自 P33 自己的 Stage I，由 P33 Stage I best 初始化，5000 步，取 last student。
  - 同一 guard [.25, 4]、連續兩次越界；q0 取自 P33 自己的 Stage I。
- 設定開關為 opt-in：`adversarial_representation: uncertainty|prob_2_entropy`（預設 `uncertainty`）；metadata 記錄 representation 與通道數。
- 命名：「controlled optical IntraDA-style (AdvEnt entropy-map) baseline」，**不是官方重現**。
