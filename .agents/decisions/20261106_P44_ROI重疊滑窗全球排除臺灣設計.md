## 1. Objective

把「GT 置中 256 patch」的取樣／評估改成「給定由完整 GT 幾何衍生的 oracle 油污錨點 → 往外擴固定範圍的區域（ROI）→ ROI 內完整重疊滑窗」
的訓練與推論流程，讓模型在油污周邊真實海面（含陸地、雲、未標註海面）上學習並受測。

## 2. Problem

現行（P12／P15）訓練用 GT-centric patch（每窗必含油）＋每景 ≤10 張全景隨機背景窗，油：背景像素曝光 1:23；
臺灣測試是 306 個以油為中心的 256 窗：
- 測試窗幾乎被油佔據，油污周邊海面上的誤判幾乎沒被考驗；
- 訓練背景窗與油污不在同一區域，模型沒學過「油污旁的海面」；
- 1:23 是人工比例，不是錨點情境下的自然比例。

## 3. Research Question

**P44 整包 pipeline（ROI 重疊滑窗取樣＋自然背景＋新 VAL 切分與選模規則）訓練出的單一 Prithvi＋DeepLabV3 artifact，
在臺灣 24 景「GT 衍生錨點 ROI」分割基準上，是否勝過三個既有 P12 artifact（同一推論與計分程式）？**

這是 artifact／整包比較，**不是**「ROI 取樣」的因果效應（兩者同時不同於取樣、切分、選模指標、訓練長度、無效像素處理）。
若日後要回答取樣本身的效果，需在相同切分、預算、無效處理、選模規則下重訓 GT-centric 對照（本卡不做）。

**已否定路線檢查（R6-1）**：現況檔③否定過背景配額／比例微調（P7、P9、P10、P18、P25 HNM）。本卡不是在 GT-centric 上調比例，
而是改變取樣單位與空間結構（背景窗來自油污周邊 ROI、比例由幾何決定），並同時改評估口徑；屬新的資料表徵／取樣結構。

## 4. Hypothesis

預期 P44 在 ROI 口徑下 annotation-relative precision 明顯較高（學過油污周邊海面），recall 可能略降（背景約佔 97% 窗）；
若 precision 增益大於 recall 損失，ROI pooled OilIoU 高於 P12。主要風險：模型塌縮成低預測／全背景。

## 5. Method

### 5.1 資料範圍與切分（使用者裁決：全球排除臺灣、VAL 方案二；不重抽、不加大小平衡）
- 候選池：355 景 − 天使輪 7 景（臺灣）− 菲律賓 MT 公主皇后號 1 景（2026-08-12 裁決）＝ 347 景。
- VAL 抽取（`build_p44_windows.py::draw_val`，seed 20261106，未用臺灣資訊）：
  - 單位：GoM／Atlantic／Pacific 以 (region, MGRS tile) 為組；具名事件以整個事件為組。
  - 19TDE、16RCT、16RBT 不可抽（固定 TRAIN）。
  - 各區名額＝round(35 × 該區可抽景數／可抽總景數)（≥1）；組以 seed 隨機排序，累計不超過名額+1 即收。
  - 洩漏移除：TRAIN 中與某 VAL 景同 event_group、同日期、WGS84 footprint 相交者 → 自 TRAIN 移除（不進 VAL）。
- 結果：TRAIN 298 景／VAL 37 景（GoM 25［16RCS 16］、千里達灣流號整事件 8、Atlantic 2、Pacific 2）／移除 12 景（全 GoM）。
- 限制（揭露、不修）：16RCS 緊鄰 TRAIN 大地點 16RCT／16RBT，別日期同海域在 TRAIN（分布相關，非像素洩漏）；
  千里達曾是 P12 VAL（本次隨機抽中）；VAL 小油污少（small 6／37）。
- 臺灣身分稽核（已執行）：臺灣 24 景與 347 景池 0 筆同景名、0 筆同 (tile, date)、0 筆 WGS84 footprint 相交。

### 5.2 ROI 規則（使用者裁決；`p44_roi.py`）
- 半開座標 [x0,x1)×[y0,y1)；油＝mask 值 0；OpenCV 8 連通。
- L_MAX＝3,430 px：**僅由 298 TRAIN 景**最大單一連通油區 bbox 長邊推導，建清單時 assert 相等（GoM 20190428_S2_15RYM，2,782×3,430）。
- 分組：油區依（面積降冪、y0、x0）排序，first-fit 依建立順序加入既有組；合併 bbox 寬、高皆 ≤ L_MAX 則同組，否則另開。
- 錨點：合併 bbox 中心 ((x0+x1)//2, (y0+y1)//2)。
- ROI：邊長 3,840＝15×256（256 格線相位最壞 255 px，14 格餘裕 154 不足，15 格餘裕 410）。
  每軸候選起點 S(n)＝{s＝256k｜0 ≤ s ≤ n−3,840} ∪ {n−3,840}，assert n ≥ 3,840（貼邊錨定，保證 ROI 恆為完整 3,840 且不越界）；
  兩軸各自獨立選：完整包住 bbox、且 ROI 中心最接近 bbox 中心者，同距取較小起點。尺寸取自各影像實際 W、H。
- 一景多 ROI：窗集合取聯集去重；計分在 ROI 像素聯集上（每像素只計一次）。

### 5.3 窗、無效像素與推論（使用者裁決：256 輸入、VRT 讀窗、背景不挑、訓練與推論皆重疊）
- 無效像素：六個模型波段（B02/B03/B04/B8A/B11/B12 原始 VRT 值）任一非有限、≤0 或 |x|>1e6；在正規化前判定。
- TRAIN：ROI 內步距 128 重疊滑窗（ROI 內起點自 rx0 起算、末窗貼齊 rx1）；無效像素 >10% 的窗剔除；
  保留窗內的無效像素在 loss 中設為 ignore(255)。共 270,469 窗，剔 4,973，保留 265,496（含油 7,123）。
- VAL（選模）：ROI 內步距 256（ROI＝15×256 恰好鋪滿）、無 TTA；不剔窗；logits 貼回 ROI 聯集（ROI 重疊處平均），
  在 ROI 聯集∩有效像素上算 pooled 油 IoU。37 景 40 ROI、8,724 窗。此為與測試算子不同的計算近似；
  訓練結束後另以測試算子（步距 128＋TTA）報 best checkpoint 的 VAL 值作診斷，**不得**據此改選 checkpoint。
- 臺灣測試：ROI 內步距 128，每窗 TTA（原圖＋hflip＋vflip logits 平均，同 baseline recon `_tta_predict_prob`），
  重疊處 logits 平均後 argmax；在 ROI 聯集∩有效像素上計分。24 景 27 ROI、21,966 窗（927 窗無效 >10%，照推論、計分排除無效像素）。
- 標籤順序（兩種 255 不混用）：先 raw {0→油 0；1、2、255→背景 1}（同 P12 與 11-03 規則；新增 5 景標註外＝背景），
  **之後**才以影像有效遮罩把無效像素覆寫成內部 ignore 255。計分另傳 boolean valid 遮罩，不以數值 255 判定。
  precision／FP 皆為相對現有標註（annotation-relative）。
- 無效剔窗稽核（已執行）：TRAIN 剔 4,973 窗中含油窗 26、油像素 53,771（全 TRAIN 窗油像素 34,254,386 的 0.16%）；
  剔除率 Atlantic 3.1%、GoM 1.0%、具名事件 1.6%、Pacific 0%；12 景剔除 >20% 窗；保留窗平均無效像素比例 3e-5。

### 5.4 模型與訓練
- 同 P12：Prithvi-EO-2.0 300M（八槽 VRT /10000 → 選 B02/B03/B04/B8A/B11/B12，官方 mean/std；B01/B08 identity）
  ＋DeepLabV3 ASPP(6,12,18)，layer 23；Tversky α0.3/β0.7（oil-only、整 batch 加總、smooth 1、ignore 255）；
  增強（RandomResizedCrop 0.9–1 p.5、翻轉、Rot90 p.8、GaussNoise p.4、亮度對比 p.3）；AdamW wd 1e-3、lr0 5e-5、
  backbone×0.1、grad clip 1.0、batch 16、AMP。
- 專用訓練程式 `train_p44.py`（不改共用 `main/deeplab_adapter.py`，以免動到其他凍結實驗的程式 SHA）：
  模型由 `DeepLabAdapter` 建構；資料集沿用 `SegmentationDataset` 的 VRT 讀窗路徑，子類別只加「無效像素→255」；
  決定性設定沿用 `main_runner.set_global_seed`＋`CUBLAS_WORKSPACE_CONFIG`；GPU 鎖沿用共用 lock；wandb 線上：初始化失敗即中止訓練，之後單次 log／finish 失敗只記錄不中止（數值訓練優先）。
- 訓練長度：虛擬 epoch＝4,000 optimizer steps（64,000 窗）；取樣器在全量 permutation 上連續取段，跨尾端才以 (seed, pass) 重新洗牌；
  每虛擬 epoch 後 VAL；CosineAnnealing T_max＝160,000 steps、eta_min＝lr0×0.01、逐步更新；上限 40 虛擬 epoch（160k steps），
  patience 8（32k steps）。不支援 resume：中斷即整個重跑，不續跑。
- 與 adapter 同構清單（機器可讀）：`train_p44.py::PARITY`，並寫入每次執行的 `resolved_config.json`（含 config、程式 SHA、清單 SHA）。
  DataLoader drop_last=True、batch 16；取樣器每虛擬 epoch 的 index SHA 與首尾 ID 寫入 `sampler_log.json`；
  Compose seed、worker seed（loader_seed＋wid）同 adapter。
- 中斷重跑政策：未正常完成（early stop 或 160k 上限）的 attempt 一律不得進臺灣評估；其 `train/` 改名 `train_failed_attempt<N>/` 保留 log，
  再從頭重跑；第一個正常完成的 attempt 才是 P44 artifact。`train/` 有有效完成記錄（且其 resolved_config 與現行凍結
  config／程式／清單／來源報告一致）時，launch.sh 永久跳過訓練、只續跑後續階段；無有效完成記錄時拒跑。
- 實作 smoke（已執行，不讀臺灣 GT）：Tversky 在實際 AMP＋GradScaler＋unscale 路徑、真實模型上，全背景／單一油像素／一般含油／含 ignore
  四種 batch 之 loss 與參數梯度皆 finite；**全背景 batch 梯度範數約 6.6e-5（含油 batch 約 1.3）**——batch 加總 Tversky 下，
  無油 batch 幾乎不提供學習訊號，背景主要在與油窗同 batch 時起作用（約 65% batch 無油；屬本設計的已知性質，不修）。
  訓練 smoke 實測約 10 it/s（4,000 步約 6.6 分；160k 步約 4.4 小時＋VAL）；VAL 3 景約 10 秒。
- 選模：VAL pooled 油 IoU（使用者裁決）。best checkpoint SHA 鎖入 `train_complete.json` 後，才以測試算子跑 VAL 診斷（`predict_p44.py val_diag`）。另記：每 batch 含油窗比例、loss、梯度 finite、VAL 預測油／GT 油比、
  small／medium／large 與 region 分層油 IoU（只作診斷）。
- seed：單次，有效 seed 42（使用者裁決）。
