# HNM_SI 改寫到 P45 k=4 管線（困難背景＋光譜指數安全閘）

> 逐輪原文：repo `GT_expand/analysis/hnm_si_p45_20261107/consensus/`（`claude_r1`–`claude_r4`、`codex_r1`–`codex_r4`）。
> 承接 [[20261106_P45_每batch固定含油窗數]]（H0＝既有 P45 k4）。

## 1. 參與與回合

- 參與：Claude（主持）、Codex gpt-5.6-sol。
- R1 REVISE（6 blocking）→ R2 REVISE（2 blocking）→ R3 ACCEPT → R4（實作後 smoke 發現問題）ACCEPT。

## 2. 起因

使用者決定在 P45 k=4 上做 HNM（hard negative mining），提供舊大圖版 `preprocess/HNM_SI`
（11 波段 ResNet50、5-fold、以 MNDWI／NDI_B1_B11／SR_B1B2_B3B8A 的 Ledoit-Wolf Mahalanobis d_si 過濾），
要求改寫到可用並與 Codex 討論。

## 3. 關鍵查證

- VRT 8 slot ＝ B01, B02, B03, B04, B08, B8A, B11, B12。
- DN ＝ 反射率 ×10000 ＋ 1000：S2 L1C 的 RADIO_ADD_OFFSET=-1000 證實；Landsat 由暗水地板恰 1001 推定；
  298／298 景的 0.1 百分位＝1001。→ **SI 計算前必須先扣 1000**。
- TRAIN 純背景窗中，已標背景 ≥70% 者占 41.1%。

## 4. 共識規則

- **FP 定義**：只算已標背景（raw 1／2）且 p>0.5 的像素。
- **合格窗**：known ≥ 0.70；候選 FP ≥ 256 px。
- **SI 安全閘**：S2／Landsat 各一組 Ledoit-Wolf Σ；T＝陽性對照 Q95；d ≤ T 者剔除。
- **R4 修訂**：陽性對照改為 leave-one-256-block-out（固定 50/50 切分會使 42／298 這類小油污景沒有指紋）。
- **替換規則**：只替換「H0 原窗本身合格」的背景 slot；同景、同 known／valid strata；每 batch ≤6；IoU ≤ 0.5。
- **gate**：92k 與 160k 兩個長度，overall ≥0.25、S2 與 Landsat 各 ≥0.20；不過不得訓練。
- **礦工**：P45 k4 best（TRAIN-only mining with a VAL-selected probe）。
- **H0**：既有 P45 k4（同 seed、同串流的歷史對照；GPU 非逐位元重現）。
- **H1 的 VAL 結果不得回頭修改任何規則。**

## 5. 結果（實作與驗證）

- 程式 commit：b4ae2a3、a2022d7。
- 42 項測試全過：含重建串流與 P45 k4 實際 23 epoch 的 sampler_log SHA 逐一相同；訓練迴圈與 `train_p45` 逐字相同。
- 全 TRAIN si_reference：S2 T＝0.596（1,225 對照）、Landsat T＝0.283（331 對照）。
- GPU smoke 全流程通過。
- 可替換上限：overall 0.389／S2 0.375／Landsat 0.446。
