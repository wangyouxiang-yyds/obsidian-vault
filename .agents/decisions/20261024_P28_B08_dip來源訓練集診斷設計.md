## 1. Objective

檢驗局部近紅外油／背景分布的可分性，能否作為光學 EUDA-PLR Stage 2 偽標籤 strong／weak 分級的候選物理訊號。這一步只測來源訓練集上此訊號是否與既有模型的已標區域品質同向，供決定是否值得做獨立資料與 target 驗證。

## 2. Problem

Zhu et al. (2022, *Optical Extraction of Oil Spills From Satellite Images Under Different Sunglint Reflections*, DOI `10.1109/TGRS.2022.3213590`) 的 FOCI 以純油／純海水的 NIR Rayleigh-corrected reflectance（Rrc）分布，各取 50% 混合後計算 Hartigan dip。本資料的 B08 是 Sen2Like 儲存值，尚未證實是原文所需的 Rrc；原始 GT=1 是 LabelMe `background`，尚未證實為純海水。因此本實驗只能稱 **B08-dip proxy**，不是原論文 FOCI 重現，也不是已證明的油／海水可分性。

P27 已發現單一可見光比值的固定方向跨日期不穩定；dip 的分布可分性不預設油相對背景亮或暗，但高 dip 也可能來自雲、耀光、船隻或模型選取錯誤。要回答 Stage 2 的問題，必須直接檢查 proxy 與偽標籤品質的關係，不能只看 dip 圖或用 GT 決定推論規則。

## 3. Research Question

在 P14 GoM-only R1 source train、2021 年及以前的 Sentinel-2 有油 patch 中，使用既有 frozen `best.pt` 的預測油／背景 B08 值計算的 B08-dip proxy，是否隨已標區域的預測 Oil IoU 提高，且相較 IntraDA 的平均 entropy 排序提供額外的來源端訊號？

**已否定路線檢查（R6-1）**：已查現況檔③：VAE+RX 直接把「異常」當油污偵測器已被否定；P27 否定單一 Wakashio 比值作目前 Stage 2 優先候選。本案是既有分割模型預測之局部分布診斷，不用 RX 直接偵測油，也不是把 P27 比值換名稱重跑。若 proxy 無法預測偽標籤品質，應否定此具體候選的優先性。

## 4. Hypothesis

若模型預測的油／背景確有局部光學分布差異，50:50 混合的 B08 dip 應傾向在較高 Oil IoU 的 patch 取得較高分數。此關聯須在日期等權的主樣本上出現，且強於 mean patch entropy 的方向校正分數；否則不把「看得分開」直接稱為 strong 偽標籤。

## 5. Method

- **固定來源與單位**：P14 GoM-only R1 `train_oil.txt` 中取得日期≤2021 的 Sentinel-2 70 景／593 個有油 patch 為全量覆蓋稽核。主分析採 P27 前已固定的 `annotated_bg_review_candidates.csv`：按 GT 類別數量選出的 14 景各一個 patch，14 個日期各等權，不再依本案分數或 IoU 改選。該 14 景共有 27 個每 patch GT=0／1 各≥100 的 patch，只作次要敏感度；同景多 patch 不當獨立日期。候選表：`/home/alanyh/oil_dataset/new/_euda_optical_metadata_20261017/wakashio_ratio_pilot_20261024/annotated_bg_review_candidates.csv`。
- **模型與預測**：唯讀載入 P14 GoM-only R1 frozen `best.pt`，沿用原六波段順序、前處理、固定分類閾值及 3-view TTA；不微調、不訓練、不以本次 GT 調門檻。紀錄 checkpoint、程式／設定與清單路徑及 hash。先做推論 parity 與輸入／標記對齊檢查；不通過則停止，不以近似推論代替。GT=0 為油、GT=1 為原始已標背景、GT=255 一律忽略；GT TIFF 的 nodata metadata=0 與油代碼衝突，需按原始類別值唯讀，不讓 masked read 吞掉油。
- **B08-dip proxy**：每 patch 僅在 B08 有效、且模型二值預測油與背景各≥100 像素時計分。由兩個預測類別的 B08 有效值各取 **512 個等分位數樣本**，形成固定 1:1、共 1,024 值的混合分布，計算 `diptest.dipstat`。固定樣本數避免 dip 隨兩類像素數增加而不可比；兩類原始像素數、油面積比例及有效／無法評分原因另列。`dipstat` 是分布形狀統計量，**不給油的高／低方向**；不能把無法評分的 patch 記為 weak 或 0 分。數值和取樣方法不宣稱與 Zhu 原文 Rrc 量綱等價。
- **GT oracle 對照**：僅在 14 個固定 patch，以 GT=0 與 GT=1 的 B08 有效像素各取相同 512 等分位數，計算 oracle proxy；GT 只用於研究診斷，絕不進入部署時的分數、方向或 strong／weak 門檻。GT=1 可能含非海水、薄雲或其他背景，須附 RGB／GT 對照供盲審；即使 oracle 分數高也不是純油／海水 FOCI。
- **品質與基線**：品質 `Q`＝模型預測對 GT=0／1 已標像素計算的 Oil IoU，GT=255 不進 TP、FP、FN；同時列油 recall、已標兩類像素數與預測油比例，以避免小油區或類別不平衡造成的高分錯覺。主 baseline 為同 patch 有效區域的平均二類預測 entropy，排序分數取 `−entropy`；另列 predicted oil fraction 作混雜因素／簡單對照，不以它替代品質。高 dip 可能只反映預測區域比例或場景光照，需畫 scatter 與逐日期表檢視。
- **主 estimand 與聚合**：`_kind=patch`，在預先固定的 14 日期／景各一 patch 上，計算跨有效日期 `Spearman ρ(B08-dip proxy, Q)`，及 `ρ(−mean entropy, Q)`，兩者差 `Δρ=ρ_proxy−ρ_entropy`；每日期等權。只在兩項分數與 Q 都有效的相同日期比較；並列逐 patch 的分數、Q、entropy、預測油比例及不可評分原因。27 patch 敏感度須按日期聚合／標示同景依賴；593 patch 僅報分數覆蓋率和無法評分成因，不在缺乏 GT=1 的 patch 假算 IoU。

**對照組與 estimand（R6-2）**：對照是現有模型的 `−mean patch entropy` 排序；同一 frozen checkpoint、同一 patch 與同一 GT 品質終點，只改品質排序用的訊號，並另報 predicted oil fraction。這是觀察性關聯比較，**不是**只改一項的 Stage 2 訓練受控實驗；若兩分數相關或受預測油比例共同影響，不可歸因於 dip。來源訓練集的模型表現屬 in-sample，不能推論 target 品質或域轉移收益。已知 pre-2022 source val 共標註僅 1 patch、GT1 約 53 像素，不足以作獨立驗證統計。

## 6. Expected Evidence

- **最低有效量**：14 固定日期中，兩種分數與 Q 共同有效的日期至少 **10 個**；不足則「不可判定」。若 Q 全相同、entropy 或 proxy 常數而 Spearman 無定義，也判不可判定。
- **支持把此 proxy 作下一輪候選**：`ρ(B08-dip proxy,Q) ≥ 0.50`，且 `Δρ ≥ 0.15`，兩條同時成立。僅表示值得在獨立 source／target 上繼續驗證，**不是** Stage 2 strong／weak 已成立。
- **否定目前候選優先性**：`ρ(B08-dip proxy,Q) ≤ 0` 且 `Δρ ≤ 0`，兩條同時成立；其餘結果為「不可判定」，不因 oracle dip 或挑出的好圖改判。門檻為本案事前研究決策規則，並非 Zhu 論文的驗證門檻或統計顯著性界線。
- **須呈現的圖表**：14 日期 proxy–Oil IoU 散點圖（註明日期、entropy 與 predicted oil fraction）、proxy 與 oracle proxy 對照、逐 patch 預測／GT／B08 與分數、27 patch 敏感度、593 patch score coverage。類別不平衡、GT 背景污染、Sen2Like B08 非 Rrc、固定樣本數近似、train in-sample 與小樣本相關估計的不確定性均在結果卡保留；不能據此宣稱 target strong／weak 或 segmentation 改善。

## 7. Evidence / Result

- **來源與覆蓋**：P14 GoM-only R1 source train 的 70 景／593 個 S2 有油 patch 中，548 個（92.4%）可計算 B08-dip proxy。45 個無法評分：33 個模型未預測任何油、9 個未預測背景、3 個僅有 1–99 個有效預測油像素。無法評分者保留 missing，不視為 weak。
- **主分析**：事前固定 14 日期各一 patch，13 日期可計算 proxy；2020-08-31 的 patch 模型沒有預測油，雖然已標區域 Oil IoU=0，仍不得補 0 dip。`_kind=patch`、日期各一票：`ρ(proxy, 已標區域 Oil IoU)=0.2472527473`，`ρ(−mean entropy, Oil IoU)=−0.0054945055`，`Δρ=+0.2527472527`。日期 bootstrap 的 proxy rho 95% 描述性區間為 `[-0.4155, 0.7945]`，跨度很大；此區間不取代事前判準。
- **次要診斷**：13 個主樣本的 GT-oracle dip 與預測遮罩 proxy 的 Spearman rho 為 `0.8132`，只表示兩種 dip 排序有關，不代表預測油是對的。14 景共 27 個具足量 GT0／GT1 的 patch 中，26 個可評分；以景內平均後跨 13 景的 proxy–IoU rho 為 `−0.0769`，主樣本的正向關聯對選 patch 敏感。主樣本 predicted oil fraction 對 IoU rho `0.5769`，顯示簡單面積訊號可能比 proxy 更貼近此訓練集終點。2020-03-04 為具體反例：proxy `0.02148` 較高，但已標區域 Oil IoU 僅 `0.2928`。
- **來源檔**：程式與完整說明在 `/mnt/backup/alanyh/oil_IR_Fullband/OIL_PROJECT_MutiBand_GT_expand/analysis/foci_pilot_20261024/README.md`；數字正本、逐 patch 表、parity 與圖在 `/home/alanyh/oil_dataset/new/_euda_optical_metadata_20261017/foci_pilot_20261024/`，其中 `summary.json`、`per_patch.csv`、`sensitivity_scene_means.csv`、`primary_scatter.png`、`all593_coverage.png`、`primary_gallery/index.html`。既有模型六波段與 3-view 推論於固定 patch 上對原 full-scene 程式的硬標籤 parity 為 65,536／65,536，詳 `parity.json`。
- **全量視覺化補記**：依使用者要求，70 景／593 個 patch 均已輸出逐張圖。瀏覽入口：`/home/alanyh/oil_dataset/new/_euda_optical_metadata_20261017/foci_pilot_20261024/all_70_scene_patches_visualized/index.html`，含 70 個場景頁、593 張不同 PNG、593 列 `manifest.csv`，另有 dip 高→低與低→高排序頁；同目錄 `validation.json` 核對數量與圖像連結。已標區域 Oil IoU 只在 GT0／GT1 足量時提供；其他 patch 僅顯示可計算的 dip（或無法評分原因）與已知油 recall。這批圖不增加新的品質證據，也不改變第 8 步「不可判定」。

## 8. Answer / Finding

**三選一：不可判定。**13 個有效日期達到事前至少 10 個的最低量；`Δρ=+0.253` 達支持條件的 `≥+0.15`，但主 rho `0.247` 未達 `≥0.50`，因此不能判支持。rho 為正、差值也為正，沒有同時符合否定條件 `rho≤0` 且 `Δρ≤0`。27 patch 敏感度方向反轉，且高 dip 可伴隨低 IoU，不能把 proxy 高直接叫作 strong。

此結果僅是 frozen P14 模型在**自己的 source training patches** 的觀察性排序關聯。B08 的 Rrc lineage 未核實，GT=1 也不是已驗證純海水；本實驗沒有重現原論文 FOCI，沒有做 Stage 2 訓練或 target 驗證，更沒有測試分割性能改善。

## 9. Decision / Next

- **這條路線**：保留為待驗候選，先改設計，不依這 13 日期直接制定 strong／weak 門檻，也不因 oracle dip 的高相關而升格為可部署訊號。當前最需要的是獨立且有油／已確認海水標註的來源或 target patch、B08 處理層級核對，以及固定模型後比較 dip、entropy、預測油比例的獨立品質排序。
- **未排除的替代解釋**：訓練集內評估樂觀偏差；背景標註含非海水／雲；B08 儲存值與論文 Rrc 不等價；預測油比例、場景光照與 GT 類別不平衡影響分數；14 日期主樣本選擇與單景多 patch 依賴。現有 pre-2022 source val 只有一個共標 patch 且 GT1 約 53 像素，不足作同樣獨立統計。
- **下一張卡**：待取得可用獨立標註與輻射 lineage 後再設計；目前無已授權 Stage 2 訓練或 target 驗證。
