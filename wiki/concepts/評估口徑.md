# 評估口徑

## 一句話定義

同一評估範圍內，**先於每個 run 加總 TP／FP／FN 像素，算一次 `OilIoU = TP/(TP+FP+FN)`；再對 seed／fold 的 run 指標取平均**。2026-10-11 起的研究呈現採此口徑，舊卡原判定不追改。來源：vault `CLAUDE.md` §6、institution `research/oil_spill_project_status.md` 評估規則及 [P48](../experiments/20261109_P48_H1prime與P44補seed_結果.md)。

## 在本專案的應用

| 問題 | 報告方式與邊界 |
|---|---|
| 臺灣比較 | 依 2026-11-11 使用者裁決，**大林 2 張**與**其他 22 張**分別於每 run 加總像素算 IoU，再跨 seed 平均，列出所有 seed 與 SD；24／19／5 可作歷史名冊說明，不再當現行成績欄。大林約占 24 張已標油像素 58%，合併 pooled 容易遮蔽其他景。來源：institution 現況檔「臺灣結果呈現改為大林 vs 其他 22 張」及 [P48](../experiments/20261109_P48_H1prime與P44補seed_結果.md)。 |
| 單 seed | 標「描述性」，不可僅憑單次差值推穩定改善。[P44](../experiments/20261106_P44_ROI自然比例基線_結果.md) S44 塌縮，引用三 seed 基線必揭露。 |
| 跨流程比較 | GT-centric 256 GT-aware 窗、3840 ROI、全景盲掃的像素分母與選區不同；逐景等權、scene-macro、run 內 pooled、逐折 pooled 平均、全語料 pooled 也不同，不能只憑同名 OilIoU 直接相減。來源：[GT-centric 歷史流程](../pipeline/GT_expand_pipeline.md)、[P44 ROI](../pipeline/P44_ROI滑窗基線.md)。 |
| 舊 Evaluation Contract | P7/P9/P10 的 `S=(M1+M2)/2` 是 355 景三折、region×size 宏觀與 per-scene mean 的特定 estimand，12 事件群 bootstrap；不等於現行臺灣 ROI pooled 指標。來源：[Contract v1](../experiments/20260716_資料溯源洩漏與評估合約v1.md)、[P9](../experiments/20260831_P9油背像素比例bracket_inconclusive與凹性發現.md)。 |

報任何量化結果須附資料名冊／ROI 或窗的測試覆蓋、模型及 checkpoint 版本、`_kind`、聚合方式和所有 seed；若與已作廢數字相關，先查 [勘誤表](../corrections.md)。
