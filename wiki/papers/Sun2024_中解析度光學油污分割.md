# Utilizing deep learning algorithms for automated oil spill detection in medium resolution optical imagery（Sun et al., 2024）

> 來源：https://doi.org/10.1016/j.marpolbul.2024.116777
> 發表：Marine Pollution Bulletin 206, 116777
> 收錄狀態：第一輪紀錄；主要方法表與波段已核對，事件分組方式仍需全文再審。

---

## 核心貢獻

建立涵蓋全球十個油污事件的 Sentinel-2、Landsat-8、Landsat-9 中解析度光學資料，系統比較 U-Net、DeepLabV3+、BiSeNetV2 及三種注意力模組，並把 sun-glint reflectance 當額外輸入。這是目前與本專案感測器及共同波段最接近的文獻，但未建立「海外來源訓練、台灣完全封存」的 target-blind protocol。

## 關鍵方法

- 143 張原始影像：60 張 OLI/OLI2、83 張 MSI。
- ACOLITE Rayleigh-corrected reflectance；Sentinel-2 波段重採樣至 20 m。
- 六個共同波段輸入，加上可選的 sun-glint feature。
- 比較 U-Net、DeepLabV3+、BiSeNetV2，並整合 SE、CBAM、SimAM。
- 以 sliding window 產生 `512×512×6` patch；翻轉與旋轉增強。

## 資料、波段與切分

| 項目 | 內容 |
|---|---|
| 感測器 | Sentinel-2 MSI、Landsat-8 OLI、Landsat-9 OLI2 |
| 六波段 | Blue、Green、Red、NIR、SWIR1、SWIR2 |
| 中心波長 | 約 482–492、559–561、654–665、864–865、1608–1614、2186–2202 nm |
| IR 類型 | **NIR + SWIR；沒有使用 TIR 作模型輸入** |
| 地區 | 全球十個已報導的慢性或事故油污案例 |
| 樣本 | 4,120 個含標註 patch，增強後 24,720 |
| 切分 | 文中為 80% train/validation、20% test；是否嚴格按事件分組仍待核對 |
| Zero-shot 判定 | **未證明**；沒有台灣封存測試，也不能由跨國資料直接推定事件獨立 |

## 重要數據／結果

- 最佳組合為加入 sun-glint feature 的 U-Net+CBAM。
- micro-F1 由 standard U-Net 的 82.8% 提升至 88.8%。
- macro-F1 約由 72.4% 提升至 73.1%。
- 測試圖仍以油污附近 crop 為主，不能等同 oil-unknown 全景或 sealed-region deployment。

## 與本專案的關聯

這篇是目前最重要的感測器 baseline：六個波段與 Sen2Like 的 S2/L8/L9 共同 VIS+NIR+SWIR 波段高度相容，可直接支撐公平模型比較、波段對齊與 sunglint conditioning。研究差異則應放在 protocol：本專案要求 Taiwan 影像、標註、統計與結果皆不得參與訓練或選模，且來源端應以事件分組驗證 transportability。

## 研究缺口與假設

- 需全文確認 train/test 是否按 incident 分組；若只是 image/patch random split，可能有事件洩漏。
- 80/20 global split 不等於 geographic zero-shot。
- sun-glint feature 依賴幾何與風場資料，其跨海域可得性與誤差需另驗證。
- 油污附近 crop 的高 F1 無法直接回答台灣完整海域的 false alarm burden。

## 九步分析摘要

1. **領域地景**：中解析度多光譜光學語意分割與注意力模型比較。
2. **矛盾偵測**：資料來源全球化，不代表測試 protocol 已隔離事件或地區。
3. **引用鏈**：上游包括 ACOLITE、水面 sunglint 物理、U-Net／DeepLabV3+／BiSeNetV2。
4. **研究缺口**：缺 sealed target-region 與明確 event-held-out 報告。
5. **方法審核**：跨三感測器共同六波段設計很強；切分單位是可信度關鍵。
6. **假設殺手**：若同事件影像跨 split，88.8% 不能代表陌生海域能力。
7. **知識地圖**：直接連到 Sen2Like 波段對齊、sunglint 與跨海域 transport gate。
8. **文獻綜合**：最接近本專案資料設定，但不是本研究主問題的直接前例。
9. **So What**：應列為第一優先全文閱讀及 baseline reproduction 對象。
