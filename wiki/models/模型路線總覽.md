# 模型路線總覽

現行研究基線為 **[P44 自然比例 3840 ROI＋Prithvi／DeepLabV3](Prithvi_DeepLabV3.md)**，2026-11-10 由使用者裁決；同模型家族在 GT-centric 階段的分數不可直接當 P44 對照。來源：[P44 結果](../experiments/20261106_P44_ROI自然比例基線_結果.md)、[P48 補 seed](../experiments/20261109_P48_H1prime與P44補seed_結果.md)。

| 主題 | 本案中的用途與界線 |
|---|---|
| [Prithvi＋DeepLabV3](Prithvi_DeepLabV3.md) | GT-centric 歷史主線及 P44 ROI 基線；取樣與評估須分清。 |
| [DADS-SAM 與 SAM hybrid](DADS-SAM.md) | 六波段監督式替代模型，GoM-only／全資料名冊各有自己的口徑。 |
| [LFMDA](LFMDA.md) | SegFormer-B2 source-only、PCD、SAM/LRH；GT-centric 與 P49 ROI 階段不能互排。 |
| [光學 EUDA／IntraDA](EUDA_IntraDA.md) | 對抗式對齊與自訓練原型；已知失效限各卡的配置。 |
| [SpectralGPT+／UperNet](替代模型_SpectralGPT_UperNet.md) | ROI 上的 encoder／head 探索，資料配方不完全相同。 |
| [iForest／DeepRX](無監督_iForest_DeepRX.md) | 早期候選 patch 提示，不是 P44 像素分割成績。 |
| [早期 DeepLabV3+／OSDMamba](早期模型_DeepLabV3+_OSDMamba.md) | 0420／0422 工程經驗，不作現行模型配置。 |

量化比較須標資料名冊、模型／checkpoint、GT 是否輔助選區、run 內像素加總或歷史逐景等權／scene-macro，以及 seed。臺灣結果依 2026-11-11 規則分報大林 2 張與其他 22 張；單 seed 為描述性。來源：institution `research/oil_spill_project_status.md`「臺灣結果呈現改為大林 vs 其他 22 張」及 vault `CLAUDE.md` §6。
