# 模型路線總覽（2026-11-11）

本頁回答「試過哪些模型、現在用哪個」。模型工程設計見各模型頁；**實驗結果以對應 `wiki/experiments/` 卡為準**。不同資料範圍、測試名冊和 ROI 口徑的分數不可互排。

| 模型路線 | 階段與用途 | 記錄 |
|---|---|---|
| OSDMamba／SwinUMambaD | 早期 11 波段 sliding-window 歷史路線，非現行主線。 | [OSDMamba](OSDMamba.md) |
| ResNet50＋DeepLabV3+ | 早期八波段監督式 baseline，設定與目前 Prithvi 六波段不同。 | [DeepLabV3+](DeepLabV3+.md) |
| iForest＋Local Contrast／DeepRX＋EM | 早期無監督候選提示，不是目前的監督式分割基線。 | [無監督模型](20261111_無監督候選模型_iForest與DeepRX.md) |
| Prithvi-EO-2.0-300M＋DeepLabV3 | GT-centric P12/P14/P15 及 ROI P44 自然比例 baseline；同 backbone 但取窗與評估改版。 | [Prithvi＋DeepLabV3](20261111_Prithvi_DeepLabV3主線.md) |
| DADS-SAM 六波段、Prithvi＋SAM decoder | 曾在 GoM-only 與全球排除臺灣跑正式對照；結果須按各卡判定。 | [DADS-SAM 與 hybrid](20261111_DADS-SAM與SAM_decoder嘗試.md) |
| LFMDA SegFormer-B2／teacher＋PCD＋SAM/LRH | P37–P43 GT-centric 與 P49 ROI 搬移；stage 2 在既有試驗中未建立增益。 | [LFMDA 路線](20261111_LFMDA模型路線.md) |
| 光學 EUDA／IntraDA | 對抗對齊與 EMA 自訓練原型；P30 塌縮，P36 油量診斷未改善。 | [域適應原型](20261111_光學EUDA與IntraDA嘗試.md) |
| SpectralGPT+＋DeepLabV3；Prithvi＋UperNet | ROI 上的替代 encoder／head 探索；未取代 P44 baseline。 | [替代模型](20261111_替代模型SpectralGPT與UperNet.md) |

現行研究基線是 **P44 自然比例 ROI 3840**，不是某一個舊 GT-centric 結果；模型與資料政策須同時指明。階段結果見 [GT-centric 快照](../../outputs/20261111_GT-centric階段結果快照.md)與 [P44](../experiments/20261106_P44_ROI自然比例基線_結果.md)。
