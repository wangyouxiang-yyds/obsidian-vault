## 7. Evidence / Result

設定：單 seed S42、GoM-only、VAL 30 景（大中小各 10）；K1（local-only 同碼對照）、K2（context 讀 512）、K4（context 讀 1024）共 3 組、各 1 run。`_kind`：patch 滑窗 pooled IoU（VAL 內各 bin 像素加總後取 macro-3）。

**訓練**：K1 23:43→05:59（best step 92k、early stop 124k）；K2 →10:23（best 48k、stop 80k）；K4 →15:35（best 52k、stop 84k）。曝光 gate 三組皆 71/71，無 collapse；`completion.json` all_present=true。

凍結門檻：Δmacro-3 ≥ +.05 且 Δrecall_>20px ≥ +.10 才算「值得補 seed」。Δrecall_>20px 達標、Δmacro-3 未達 → 依卡 §7 K2、K4 皆為「不可判定」。

**各 bin IoU（無 TTA）K1／K2／K4**：large .460/.554/.562；medium .416/.380/.400；small .144/.195/.158。TTA macro-3 .347/.404/.398（Δ +.057/+.051），僅描述，卡規定不用於分類。

**K1 phenotype**：「dominated by one scene/component」，最大元件占 >20px GT 的 90%，故 Δrecall_>20px 實質上由單一元件決定。各 run 內相鄰評估點的 VAL macro-3 會跳 .05–.09，單 seed Δ≈.03 落在此波動內。

**反事實（描述性）**：derangement 使 macro-3 降 .249（K2）／.316（K4），至 .128／.058；把 local 換進 context 輸入得 .288／.301（均低於 K1 .340）；A_identity ≈51／54 → adopted。模型明顯依賴 context 輸入。

## 8. Answer / Finding

**不可判定（power 不足：單 seed、K1 interior 由單一元件主導、VAL 評估點間波動與 Δ 同量級）。**

- 與第 6 步門檻對照：Δmacro-3 +.036／+.033 落在 +.05 門檻下方；Δrecall_>20px ≥ +.10 達標但 K1 基準由單一元件決定，不足以單獨支持。不得寫成「略有提升」。
- 缺什麼：多 seed（至少能估 run 間 SD）、不被單景主導的 interior 指標。
- 描述性訊號（不改變判定）：模型確實使用 context（反事實大幅退化）；large bin IoU 上升（.460→.554/.562）而 medium 不升、small 不穩；臺灣大林在 K4 大幅上升、K2 下降，其他 22 張兩者皆小幅上升，單 seed 不可歸因。

## 9. Decision / Next

- 這條路線：暫不續跑、不收線；是否補 seed 尚待使用者決定（補 seed 非自動授權）。
