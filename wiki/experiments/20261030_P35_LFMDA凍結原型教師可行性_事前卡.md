## 前半：開跑前凍結（1-6）

### 1. Objective

在現有六波段 Prithvi＋DeepLab、GoM source 有標註／臺灣 270 個 GT 位置輔助 target 窗的條件下，先檢查 LFMDA 所用的「類別原型」是否有足以進入訓練試驗的訊號。

### 2. Problem

P29 source-only 的臺灣 270 窗 pooled Oil IoU 三 seed 平均 0.4115；P32/P33 對抗適應＋固定偽標籤三 seed 分別降到 0.1894/0.1743，主要是預測油量下降。P30/P31 線上 EMA 自訓練曾塌向全背景／全油。直接加入 PCD/SAM 會同時改多個機制，且原論文的 DINOv2 三通道教師與本案六波段不相容。先檢查凍結原型訊號。

### 3. Research question

在**目前 source 監督口徑**下，由兩個凍結 Prithvi teacher 的特徵建立油／背景原型後，GoM source 留出景是否有超過標籤打亂虛無分布的類別可分訊號，且臺灣 270 窗的原型預測不塌為單一類？

已否定路線檢查：本卡沒有對抗訓練、線上 EMA 或 target 偽標籤更新；只做兩個凍結特徵的 source/target 推論，不重試 P30–P33 方法。

### 4. Hypothesis

至少一個 teacher 的 source-val 原型 margin AUROC 高於景內打亂標籤的 95 百分位，且臺灣 image-only 270 窗有非零、非全油的原型 oil token。若不成立，暫不投入 PCD 訓練。這是可行性必要條件，不代表 PCD 對臺灣有效。

### 5. Method

| 項目 | 設定 |
|---|---|
| 候選 teacher（固定二個） | (A) 原始 Prithvi-EO-V2-300M 預訓練 encoder；(B) P29 GoM source-only S42 `best.pt` 的 encoder |
| 推論模式 | 兩者 `eval()`／無梯度；同八槽正規化後取 B02/B03/B04/B8A/B11/B12；取最後一層 16×16 token 特徵並 L2 正規化 |
| 原型建構資料 | GoM R1 Train 輸入名冊：1,188 油中心＋1,550 canonical pure-BG proxy 窗；整窗影像無效像素 >10% 排除並記數；不使用 target 建構／更新原型 |
| 主量 | GoM R1 Val（輸入名冊 312 油中心＋390 BG proxy 窗／39 景，同 >10% 整窗排除）合格景 cosine margin scene-macro AUROC |
| Null | 景內打亂 token 類標，RNG seed 20261030，99 次，取 95 百分位 |
| 不確定度 | 取得日期 cluster bootstrap 2,000 次（僅描述） |
| Target | 臺灣 19 景／270 窗，image-only，不開 target GT |
| 程式 | `analysis/p35_pcd_teacher_feasibility_20261030/run_feasibility.py` |

- 候選 teacher 固定二個：(A) 原始 Prithvi-EO-V2-300M 預訓練 encoder；(B) P29 GoM source-only S42 `best.pt` 的 encoder。兩者 `eval()`／無梯度，同八槽正規化後取 B02/B03/B04/B8A/B11/B12；取最後一層 16×16 token 特徵並 L2 正規化。
- GoM R1 Train：1,188 油中心＋1,550 canonical pure-BG proxy 窗為輸入名冊。沿用現行 `WindowDataset` 規則，整窗影像無效像素 >10% 即排除並記錄數量；兩類再排除任何含影像無效像素的 16×16 token。油原型取 raw mask 0 占 ≥128/256 且 token 沒有 255 的特徵平均；背景原型**只**取 canonical pure-BG proxy 窗特徵平均（其 raw mask 0 個已標油，但 raw 255 多，並非人工確認水體）。每類獨立平均，再 L2 正規化；不使用 target 建構／更新原型。≥90% 油門檻實際只比 ≥50% 少 17 train token、val 0 token，描述計數，不增列實驗臂。
- GoM R1 Val：312 油中心＋390 BG proxy 窗／39 景為輸入名冊；套用相同 >10% 整窗排除規則並報告排除數。主量是每景都同時有油 token 和背景 proxy token 時的 cosine margin（sim 油原型－sim 背景原型）AUROC，再對合格景等權平均；事前預計約 20/39 景合格。另報每類 ≥50 token 的景等權 AUROC、pooled AUROC、各類 token/景數、source-only decoder 在同一批 token 的 AUROC。原型 selection 只按主量較高者，若未過 gate 則不選。
- Null：固定原型/margin，在每個合格 val 景內打亂 token 類標、保留該景類別數；固定 RNG seed 20261030，共 99 次；每次重算 scene-macro AUROC。取 95 百分位。
- 取得日期 cluster bootstrap 2,000 次，僅為描述性不確定度；GoM 39 景全屬同一 collection/G3，日期不等於獨立事件，不做 event-level CI 或外推。
- 臺灣：沿 P32 SHA-pinned image-only manifest 的 19 景／270 窗；`WindowDataset(role='target')` 不設 mask_dir、不開 target GT。排除影像無效 token，對兩 teacher 報原型 argmax oil token 比例及 cosine margin 分位數；source-only 另報 decoder 佔比／與原型一致率。固定首批 target 另報 source-only student 對兩原型的 step-0 PCD CE（溫度 0.3）及 feature-gradient L2，僅機制描述。
- A 不訓練、沒有模型效益對照；原型 vs 打亂標籤為訊號虛無對照。任何後續 B 必須 matched continued-training control，3 paired seeds、兩臂 target forward/BN/RNG 一致，只差 λ_PCD，source loss 保留；B 不在本卡授權或判定範圍。
- 程式：`analysis/p35_pcd_teacher_feasibility_20261030/run_feasibility.py`；輸出新目錄，記錄輸入與程式 SHA，無覆寫。

### 6. Expected evidence

主量：GoM val 合格景 scene-macro AUROC，各候選均與自身 99 次景內標籤打亂 null 的第 95 百分位比較。

- **Go**：至少一個候選主 AUROC 嚴格大於自身 null95，且同候選 target oil token occupancy 嚴格介於 0 與 1。僅表示目前 source 監督口徑下存在可用診斷訊號，允許另設 B，不表示 teacher 或 PCD 有效。
- **No-go**：沒有任何候選同時符合兩項；暫不啟動 B。結論只能是「當前口徑未確認可用原型訊號」，不能寫成「Prithvi 不含油語意」。
- **不可判定**：source/target 覆蓋或模型載入未達固定數量、結果非有限、資料或 SHA 改變；屬工程未完成，不當方法失敗。

**限制**：GoM val 是 S42 source-only checkpoint 的選模資料，二教師比較偏向 S42；油 token 來自油中心窗，BG proxy 來自另一批窗，patch-origin confound 不可識別；BG proxy 未人工證實為水。臺灣 GT 位置先驗、pixel GT 已在 P32/P33 歷史評估讀過，故本案非 GT-free、非 blind、非未見事件泛化；target occupancy 無 GT，不能解讀為正確率。A 不測 PCD 訓練效益，也不復現 LFMDA 的 DINOv2／SegFormer／SAM 流程。

## 後半：結案才填（7-9）

### 7. Evidence / Result（實際結果）

來源：repo `analysis/p35_pcd_teacher_feasibility_20261030/RESULTS.md`（SHA-256 `8b3073b40dab4d421ebbe121d18f585729e1225247c29e91f211e95a98326635`）；正式輸出 `result.json`（見下方檔案位置）。本輪只做凍結特徵推論，未訓練 LFMDA／PCD，未讀臺灣 target pixel GT。

**輸入與覆蓋**

- GoM R1 Train：名冊 2,738 窗（156 景），>10% 無效影像像素排除 7 個 BG proxy 窗，留 2,731；原型採 19,812 油 token、395,008 BG proxy token。
- GoM R1 Val：名冊 702 窗（39 景），排除 3 個 BG proxy 窗，留 699；油 token 4,687、BG proxy token 99,072；20/39 景兩類均有（合格），僅 7 景兩類各 ≥50 token。
- 臺灣：SHA-pinned image-only manifest 19 景、270/270 窗、69,120 有效 token；`WindowDataset(role='target')` 的 `mask_dir=None`，未載入 target mask。
- 程式 SHA-256 `0bc5ba3c7d4314038bb98bdd0d87a99c63cd022a0798cdeed044f62af6c02324`、manifest SHA-256 `855a2307d229a3f436aabcc205fa50b3c278f325c35f7b40dfbaa1a440ea5162`（RESULTS.md 記載已自 `result.json` 讀回核對）；Git HEAD `48cdecae1c3aa334089f241c8daa1d62d392d8d5`，程式／卡／報告未 commit，以 SHA 定位實際版本。

**事前主量與 gate**

| 凍結 encoder | GoM val 合格景等權 AUROC（主量） | 景內打亂 null95 | 各類 ≥50 token 7 景 AUROC | pooled AUROC | 臺灣原型油 token 比例 |
|---|---:|---:|---:|---:|---:|
| (A) 原始 Prithvi-EO-V2-300M | 0.6511 | 0.5480 | 0.6343 | 0.8757 | 69.51% |
| (B) P29 source-only S42 | **0.9878** | 0.5476 | **0.9667** | 0.9395 | **9.35%** |

- 兩候選主量皆嚴格大於自身 null95，臺灣油 token 佔比皆嚴格介於 0 與 1 → **事前 gate：Go**；依事前規則主量較高者 → **teacher=S42**。
- 日期 cluster bootstrap 95% 描述區間：預訓練 0.5431–0.7572；S42 0.9665–0.9997（日期非經驗證獨立事件，不表示跨事件泛化）。

**描述性診斷（非事前判準）**

- S42 原有 DeepLab decoder（原生 16×16 head logits）在同批 GoM val token 景等權 AUROC 0.9253；臺灣 270 窗預測油 token 比例 12.16%。
- 臺灣 token 上 S42 原型與 decoder **同判 96.75%**（扣除背景多數類後 Cohen κ=0.8313、油 token Jaccard=0.7378）。原型油 6,463 token、decoder 油 8,407 token → 共同油 6,313、**原型獨有油 150、decoder 獨有油 2,094**（由總同判數推得）。屬兩決策差異，不能推為 PCD 更新後的因果效果。
- 固定首批 8 個臺灣窗、以原型 argmax 作自偽標籤：S42 student 對 S42 原型 step-0 prototype CE=0.1252、feature 梯度 L2=0.0163；對預訓練原型 CE=0.6616、梯度 L2=0.00383。僅證明 loss 可計算、梯度非零，未更新權重；兩 feature 空間尺度不同，不可直接比較訓練效益。
- 預訓練原型臺灣油 token 69.51%，遠高於 S42 decoder 12.16%，不可直接當可信油偽標籤；無 target GT，不能評其精確率／召回率。

### 8. Answer / Finding（結論）

**事前 gate：GO，teacher=S42。** 在目前 source 監督口徑下，至少一個凍結原型有超過景內打亂標籤 null 的 GoM val 類別可分訊號，且臺灣原型預測未塌為單一類。

- **不證明臺灣改善**：A 未測 PCD 訓練效果；9.35%／69.51% 是預測量，不是正確率。
- **S42 原型大多重述 decoder**：與 decoder 同判 96.75%，不一致處 2,094 vs 150，主要是原型把 decoder 的油判成背景，即原型近似 decoder 的較保守子集；而現有模型主要失敗已是漏油，尚未顯示原型提供互補知識。
- **解讀邊界**：BG proxy 只保證無已標油、非確認水體；油／BG token 來自不同窗，patch-origin confound 可能抬高 AUROC（S42 多景 AUROC=1）；GoM val 為 S42 選模資料、train/val 有取得日期交集；臺灣窗位置來自 GT 輔助且 pixel GT 曾於 P32/P33 讀過，非 GT-free／blind；未復現 LFMDA 的 DINOv2／SegFormer／SAM。
- **結果後協商**：Claude peer postrun（session `7636a263-f024-4a44-a681-c6d6dbf0b0ea`）R1 誤稱 ≥50 token 結果與日期區間缺漏，經核對撤回；R2 **ACCEPT／BLOCKING=[]**，並核實 decoder 使用原生 16×16 logits、step-0 為 target 原型自偽標籤。

### 9. Decision / Next（下一步）

- **A**：結案。
- **研究判斷**：A 依事前 gate 形式通過，但**不把 S42-PCD 當作優先改善方案**。
- **B（PCD 訓練）**：**尚未啟動**，未授權。若要做，應定位為「可能無效或傷害」的對照：同一 source-only checkpoint、source loss 保留的配對續訓，λ=0 vs λ>0 兩臂、三個配對 seed、相同 target forward/BN/RNG，僅 PCD 權重不同；事前檢查 target 油量是否下降，最終一次性評估 270 窗 pooled Oil IoU。須另立凍結卡與訓練實作，不得沿用 A 的 GO 當臺灣效果保證。
- **待辦**：程式／CARD／RESULTS 於 repo 尚未 commit（commit 需使用者明確授權）。
- **下一張卡**：無（待使用者決定是否開 B 卡）。
